# Проект "Приложение по поиску вакансий посредством сайта HH.ru"
##Описание: Это приложение представляет собой инструмент для работы с вакансиями на платформе hh.ru. Оно позволяет получать информацию о вакансиях, сохранять её
в файл, а также работать с этим файлом и фильтровать его.

## Описание модулей:
1. Список вакансий хранится в JSON-файле в модуле data.
2.В пакете src находятся модули со следующими функциями:
- В папке main в модуле application.py создана функция для взаимодействия с пользователем через консоль. Пользователь получает данные по вакансиям согласно
запросу.
Вспомогательные функции находятся в папке проекта src
- API для работы с hh.ru: Реализован абстрактный класс AbstractAPI и конкретный класс HeadHunterAPI, который подключается к API hh.ru и получает вакансии согласно заданным параметрам.
- в модуле vacancies.py реализован класс Vacancy для работы с вакансиями. В данном классе определены следующие атрибуты: название, ссылка, зарплата и
описание вакансии. Поддерживает методы сравнения вакансий по зарплате и валидацию данных.
- В модуле Vacancy_handler.py реализован абстрактный класс VacancyHandler, который определяет интерфейс для работы с вакансиями, а также создан класс JSONFileHandler, наследованный от абстрактного класса, для
сохранения информации о вакансиях в JSON-файл.

## Установка
1. Клонируйте репозиторий git clone git@github.com:Ekaterina-RA/course_design-OOP.git
2. Установите зависимости poetry install
3. Конфигурационные файлы. В проекте есть файлы конфигурации, в которых находятся переменные для записи в них путей к файлам и других параметров. 

## Тестирование.
- Проект покрыт юнит-тестами Pytest. Чтобы запустить тесты с оценкой покрытия выполните команду: pytest
- Тесты находятся в папке tests
